# NutriSnap — AI Clinical Dietician Portal

NutriSnap is a full-stack dietician-patient management web application built with React, Vite, TypeScript, Express, Firebase Firestore, and Google Gemini 2.5 Pro AI.

## 🚀 Features

1. **Dietician Dashboard**: Manage patients, view biometrics, and approve AI-generated coach responses.
2. **AI Meal Plan Generator**: Clinical AI (Gemini 2.5 Pro) reads patient health records, allergies, and goals to construct personalized 7-day meal plans with macro targets.
3. **Patient Mobile Portal**: Today's meal plan, food scanner, biometrics log (weight/water), and in-app messaging.
4. **AI Plate Scanner**: Patients take photos of their food; Gemini Multimodal Vision identifies the food, estimates portion sizes, and logs the macros directly to their health record.

## 🛠 Tech Stack
- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons
- **Backend**: Express.js (TypeScript) + Node.js
- **Database**: Firebase Firestore
- **AI / LLM**: Google GenAI SDK (Gemini 2.5 Pro)

Built for clinical dietician practice automation. Powered by Google DeepMind Gemini.
